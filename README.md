# 🧪 Katalon Sample Test

> A practical automation testing project developed using **Katalon Studio** to explore web UI testing and automated test suite management.

---

## 🧐 Project Overview
This repository contains a sample automation project built with Katalon Studio. It demonstrates the fundamental structure of an automated test project, including:
* **Object Repository:** Organized UI elements for stable test execution.
* **Test Cases:** Automated scripts designed to verify web application functionalities.
* **Profiles:** Environment-specific variables (e.g., Global Variables) for testing across different stages.
* **Groovy Scripting:** Custom logic and advanced test steps using the Groovy language.

## 🛠️ Tech Stack & Tools
* **Automation Tool:** [Katalon Studio](https://www.katalon.com/)
* **Scripting Language:** [Groovy](https://groovy-lang.org/) / Java
* **Build Tool:** [Gradle](https://gradle.org/) (via `build.gradle`)

## 📁 Project Structure
* `Lab10.1.prj`: The core Katalon Studio project configuration file.
* `Include/`: Contains custom scripts, features, and configurations.
* `Profiles/`: Storage for global variables and environment profiles.
* `settings/`: Internal project and execution settings.
